# Nome e identidade do assistente

## Por que escolher um nome próprio

Projetos de IA costumam usar nomes curtos e fáceis de lembrar porque o usuário precisa sentir que está chamando um assistente, não apenas abrindo uma ferramenta.

Exemplos comuns de estilo:

- nomes curtos;
- som fácil de falar;
- 2 ou 3 sílabas;
- boa leitura em português e inglês;
- aparência boa em logo;
- personalidade clara;
- fácil de usar por voz.

## Como nomes de IA geralmente são criados

### 1. Nome humano

Usado para criar sensação de proximidade.

Exemplos de estilo:

```text
Lia
Nina
Mira
Nara
Ayla
Luna
```

### 2. Nome tecnológico suave

Parece moderno sem ficar técnico demais.

Exemplos de estilo:

```text
Luma
Nexa
Vira
Auri
Zena
Kira
```

### 3. Nome com significado funcional

O nome lembra foco, direção, organização ou clareza.

Exemplos:

```text
Clara
Foca
Norte
Rumo
Mira
Guia
```

### 4. Nome ligado à marca

Pode conectar com a Pata 3D.

Exemplos:

```text
PataMind
PataFlow
PataFocus
PataJarvis
PataTask
```

### 5. Nome híbrido

Mistura som humano com função do app.

Exemplos:

```text
Lia Focus
Mira Task
Nara Flow
Luma Tarefas
Ayla Focus
```

## Por que muitos nomes parecem femininos

Muitos assistentes usam nomes com som mais leve, vogais abertas e final em "a", porque isso costuma soar mais amigável e fácil de chamar por voz.

Mas o app não precisa obrigatoriamente ter nome feminino. O mais importante é o nome combinar com a função.

## Critérios para este projeto

O nome ideal para este app deve comunicar:

- foco;
- clareza;
- próxima ação;
- baixa carga mental;
- organização sem julgamento;
- rotina inteligente;
- ajuda para TDAH e sobrecarga mental;
- assistente operacional, não apenas agenda.

## Recomendação provisória

Nome mais alinhado com o conceito:

```text
Mira
```

Motivo:

O app quer fazer o usuário parar de olhar para tudo e mirar apenas na próxima ação possível.

Frase de produto:

```text
Mira — menos cobrança, mais direção.
```

## Cuidados

Antes de decidir o nome final, verificar:

- se já existe app com nome igual;
- se o domínio está livre;
- se o nome é fácil de pesquisar;
- se não parece cópia de assistentes famosos;
- se funciona bem com a identidade visual.
