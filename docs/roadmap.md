# Roadmap do Jarvis Tarefas

## Fase 1 — Planejamento funcional

Objetivo: fechar o desenho do MVP.

Tarefas:

- definir categorias de tarefas;
- definir status;
- definir campos do banco;
- definir regras de prioridade;
- definir fluxo da tela Agora;
- definir fluxo da tela Hoje;
- criar prompt base da IA;
- criar schema inicial.

## Fase 2 — Protótipo básico

Objetivo: ter uma versão testável.

Funções:

- criar tarefa;
- listar tarefas;
- alterar status;
- concluir tarefa;
- adiar tarefa;
- escolher próxima ação;
- salvar histórico.

## Fase 3 — IA revisora

Objetivo: usar IA sem depender 100% dela.

Funções:

- organizar entrada bagunçada;
- sugerir prioridade;
- dividir tarefa grande;
- detectar tarefa vaga;
- sugerir próxima ação;
- gerar resumo do dia.

## Fase 4 — Notificações decisivas

Objetivo: trocar lembretes comuns por alertas com decisão.

Funções:

- alerta no horário;
- botão iniciar;
- botão concluir;
- botão adiar;
- botão dividir;
- alerta de atraso;
- alerta após muitos adiamentos.

## Fase 5 — Memória compactada

Objetivo: fazer o app aprender com o uso.

Funções:

- registrar padrões;
- resumir comportamento;
- salvar memórias úteis;
- permitir editar ou apagar memórias;
- usar memória no planejamento.

## Fase 6 — Laboratório de abordagens

Objetivo: testar quais notificações funcionam melhor.

Abordagens possíveis:

- direta;
- com motivo financeiro;
- com passo pequeno;
- com urgência;
- anti-procrastinação;
- checklist técnico.

## Fase 7 — Versão PC/Web

Objetivo: facilitar organização em tela maior.

Funções:

- painel de tarefas;
- painel de projetos;
- revisão diária;
- revisão semanal;
- edição de memórias.

## Fase 8 — Jarvis avançado

Recursos futuros:

- comando por voz;
- integração com calendário;
- integração com WhatsApp ou Telegram;
- resumo falado;
- previsão de atraso;
- sugestão de resposta para cliente;
- modo foco;
- widgets no celular.
